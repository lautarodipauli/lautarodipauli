## 📌 Featured Project

### [Academic Attendance Management System](https://github.com/lautarodipauli/TP-Java) · Java Swing desktop app

University group project (Data Structures and Algorithms II, Universidad CAECE, 2026) that manages subjects, enrollments and attendance, and generates academic standing reports.

- Loads data from XML with consistency validation, and persists state through Java serialization
- Polymorphic enrollment types (Regular, Conditional, Listener) that compute each student's academic status
- Reports exported to `.txt`: subject ranking, per-subject detail and students who lost regular status
- 🤝 Team project: my contributions were the first version of the Swing interface, the `TipoMateria` enum, the `Persona` class, the initial data loading and the report export
